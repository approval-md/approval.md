## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Make the project's agent labour a verifiable public number. A dependency-free Node script reads the local session transcripts Claude Code, Codex and Cursor leave on the maintainer's Mac, computes active hours (gaps between consecutive transcript events, each capped at 300s, attributed to the most recent assistant model), sessions, turns and tokens per model, and writes metrics/agent-hours.json. README badges (shields dynamic-JSON over raw main) show fable, opus, astra, sol, cursor and total hours. A weekly launchd-driven script refreshes the JSON through an auto-merging PR, mirroring the records-PR pattern. Why: credibility. Readers can audit how much fable/opus/astra/sol time went into the repo, with the method and its floor caveat stated. Tooling and docs only, outside M0-M8; no SPEC change. Data survey (2026-09-19): Claude transcripts under ~/.claude/projects/*approval-md*/ carry per-turn model, timestamps, usage; Codex rollouts under ~/.codex/sessions and archived_sessions carry model in turn_context.payload.model and cumulative tokens in the last token_count event, filtered by session_meta.payload.cwd; Cursor transcripts under ~/.cursor/projects/Users-carter-dev-approval-md/agent-transcripts carry no model and timestamps only inside user messages, so Cursor is hours-only and flagged approx. codex-auto-review is the guardian reviewer: bucket it as codex-review, keep it off the badges. Cloud-only sessions never land locally, so every figure is a floor.
<!-- SECTION:DESCRIPTION:END -->
