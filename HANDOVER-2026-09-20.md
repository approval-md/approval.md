## 6. Working rules learned this day

- **Batch PRs.** Backlog-only filings never get their own PR: they ride the
  next code PR or one batch at session end. A lane's tasks stack into one PR
  with one commit per task (APRV-160). A separate PR only for a
  records-advance-gated change or an enforcement-path diff reviewed alone.
- **Never stack a PR on a queued PR**: the queue removes it with
  `invalid_merge_commit` and clears its arm. Open the follow-up after the
  first lands. A push to a queued branch is rejected.
- **Stop the daemon before `approval log sync`** until 389 lands.
- **`git tag -l` classifies `release.publish`** (every `tag` subcommand does):
  never list tags from a hooked session; it puts a nine-minute question on the
  phone. Use `git log -1 --format=%d <tag>`.
- **The hook also refuses** `mktemp`, `node -e`, `time`, `git merge-base`,
  `git diff-tree`, `git show-ref`, `git config`, `paste`, and `git reset
  --hard` is human-only. `grep` on PATH is a ugrep shim that reports no matches
  on files it reads as binary: use `/usr/bin/grep -a`.
- **`dist/` is stale across branches in a worktree**; rebuild after checkout,
  overwrite a stale compiled test with `export {}`, never `rm` under dist/.
  Local `npm test` on Node v26 shows about 22 SMTP suite failures (TLS
  ServerName may not be an IP); CI on Node 22 is the truth.
- **A worktree without its own `node_modules`** resolves through the primary's
  and adds phantom packaging failures; `npm ci` first.
- **The Backlog CLI strips an `approval:` envelope** from a task file on every
  edit; re-add it with the Edit tool after the last CLI edit, then commit.
- **`approval env` never overrides a variable already exported** in the shell;
  a stale export shadows a re-stored keychain value silently. Open a fresh
  window or `unset` first. 390 turns the warning into a refusal that compares
  values.
- **The demo's agent child has `HOME` under the instance**, so macOS built its
  keychain search list without the login keychain; the resolver now retries
  with the account home (168).
- **The worktree guard refuses harness calls whose argument text contains the
  word git**, and three refusals count as failures for the loop floor: keep
  backlog note text to plain prose.
- **Verify from the state, not the report**: the false `anchor-diverged` stop,
  the 404 on a "47-character" token, and the check's "port free" while the
  server listened were each settled by reading the file or the socket.
